Architecture

Trading DB

Postgres behind the 5thstreetcapital Netlify functions. The allocation-engine worker is the only automated writer; dashboards and the mobile app read through public GET endpoints. Writes run every TRADING_DB_SYNC_SECONDS (default 900s) and are not gated on DRY_RUN.

Writes

Endpoint Writer Cadence Semantics
POST /db-orders app/trading_db.post_orders ~900s Upsert open + recent stock/option orders (engine-blob dump shape)
POST /db-positions app/trading_db.post_positions ~900s Whole-book replace — symbols absent from payload are deleted downstream
POST /db-bot-activity app/trading_db.post_bot_activity On event Append-only; deduped on {order_id}:{status}
POST /db-orders robinhood-mcp sync_trading_db Manual Batch historical order backfill from Robinhood API

Reads

Endpoint Consumers Poll Returns
GET /order-book-snapshot Dashboard (web, Netlify, API /dashboard), mobile WebView 60s Portfolio, positions, options, open/recent orders
GET /db-bot-activity Same dashboard clients 60s Bot activity feed

order-book-snapshot aggregates rows written by db-orders and db-positions; there is no separate snapshot write path.
